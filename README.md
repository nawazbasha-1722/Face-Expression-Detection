# Face Expression Detection Web App

A real-time facial expression and emotion detection web application built with Flask, OpenCV, and FER (Deep Learning).

## Features
- WebCam frame analysis for real-time dominant emotion detection.
- Image upload feature to detect emotions from static photos.
- Modern responsive HTML5/CSS3 user interface.

## Local Setup
```bash
pip install -r requirements.txt
python app.py
```
Open `http://localhost:5001` in your browser.
